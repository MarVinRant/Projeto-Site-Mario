# 🍄 Mario Bros Plumbing

> 💡 Este projeto faz parte da minha jornada como Desenvolvedor Web.
> Cada aplicação foi desenvolvida para resolver um problema real ou simular desafios encontrados no mercado, buscando aplicar boas práticas, evolução técnica e foco na experiência do usuário.

---

## 📖 Sobre o projeto

O **Mario Bros Plumbing** é uma Landing Page desenvolvida para representar uma empresa fictícia de serviços hidráulicos inspirada no universo do Mario Bros.

Este foi um dos projetos mais importantes da minha trajetória, pois marcou meu primeiro contato com JavaScript aplicado à interação entre HTML, CSS e comportamento da interface.

Mais do que reproduzir um layout, este projeto despertou meu interesse pelo desenvolvimento Front-end ao mostrar como pequenas interações podem transformar completamente a experiência do usuário.

---

## 🎯 Objetivo

Desenvolver uma Landing Page moderna, responsiva e interativa para apresentar uma empresa de serviços hidráulicos de forma criativa, utilizando JavaScript para tornar a navegação mais dinâmica.

---

## 🎯 Desafio

O principal desafio foi compreender como HTML, CSS e JavaScript trabalham em conjunto para criar interfaces interativas.

Foi nesse projeto que comecei a utilizar a inspeção de elementos do navegador para entender estilos, identificar problemas e aprender a modificar interfaces de forma prática.

Esse processo mudou completamente minha forma de estudar desenvolvimento Front-end.
